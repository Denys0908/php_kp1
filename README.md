# КП-1: Розробка PHP-структур та вивід результатів у вебсторінку

**Дисципліна:** Сучасні технології розробки WEB-застосувань мовою програмування PHP  
**Варіант:** 11 - Система обліку студентів та оцінок  
**Виконав:** Сардаковський Денис Олександрович, група ІК-44 (ФІОТ КПІ)

## Структура проєкту

- `index.php` - масив даних студентів (`name`, `group`, `avgGrade`), типізована функція форматування, умовна логіка визначення статусу («Відмінник» при балі `>= 90`), обчислення середнього балу по групі та вивід у HTML-таблицю.
- `style.css` - стилізація сторінки, таблиці, бейджів статусів та підсумкового блоку.

## Локальний запуск

Вимоги: встановлений PHP 8.x.

1. Клонувати репозиторій та перейти в папку проєкту:
   ```bash
   git clone https://github.com/Denys0908/php_kp1.git
   cd php_kp1
   ```
2. Запустити вбудований сервер PHP:
   ```bash
   php -S localhost:8000
   ```
3. Відкрити в браузері: http://localhost:8000/index.php
